# 🏥 Hospital Management System

A comprehensive C++ console-based Hospital Management System designed to efficiently manage hospital operations, patient records, and administrative tasks.

![C++](https://img.shields.io/badge/language-C%2B%2B-blue)
![Version](https://img.shields.io/badge/version-1.0-green)

## 📋 Features

### 🧑‍👤 Patient Management
- Add new patient records
- Update existing patient information
- Search for patient records
- View patient history
- Generate patient reports

### 👨‍⚕️ Doctor Management
- Register new doctors
- Manage doctor schedules
- Track availability
- Assign specializations
- View doctor's patient list

### 💰 Billing System
- Generate patient bills
- Process payments
- Track pending payments
- Generate financial reports

## 🛠️ Technologies Used
- C++ Programming Language
- Data Structures (Arrays, Linked Lists, etc.)
- Object-Oriented Programming Concepts

## 📥 Installation

1. Clone the repository
```bash
git clone https://github.com/Barcha22/Hospital-Management-System-in-Cpp.git
```

2. Navigate to the project directory
```bash
cd Hospital-Management-System-in-Cpp
```

3. Compile the program
```bash
g++ main.cpp -o hospital_system
```

4. Run the executable
```bash
./hospital_system
```
